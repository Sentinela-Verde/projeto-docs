# Responsabilidades

## Objetivo

Registrar as responsabilidades de cada integrante sem criar hierarquia.

| Frente | Responsabilidade |
| --- | --- |
| 🛰️ Dados / Geoprocessamento | Fontes geoespaciais, área de estudo, preparação e validação espacial |
| 🔧 Engenharia de Dados | Ingestão, organização, processamento, qualidade e disponibilização |
| ☁️ Cloud / DevOps | AWS, infraestrutura, automação, versionamento e execução |
| 🤖 Ciência de Dados / Modelagem | Features, dataset, treinamento, avaliação e classificação |
| 📊 Indicadores / Análise | Métricas, áreas, percentuais, comparações e análise temporal |
| 📈 Resultados / Documentação | Integração, mapas, gráficos, documentação e apresentação |

> Os nomes dos responsáveis serão definidos pelo grupo. Atribuições representam frentes de trabalho, não cargos.
