# Colaboração / Pair Programming

## Onde a colaboração conjunta gera maior benefício

### 🛰️ Dados ↔ 🤖 Modelagem

Definição de features, rótulos, alinhamento espacial e dataset para ML.

### 🔧 Engenharia de Dados ↔ ☁️ Cloud / DevOps

Implementação de armazenamento, execução, automação, infraestrutura e CI/CD.

### 🤖 Modelagem ↔ 📊 Indicadores

Definição das saídas do modelo necessárias para produzir os indicadores.

## Regra

Pair programming é direcionado às interfaces críticas; não é necessário aplicar a prática a todas as atividades.
