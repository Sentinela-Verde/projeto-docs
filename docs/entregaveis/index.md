# Entregáveis

Esta seção reúne os materiais produzidos ao longo do projeto para acompanhamento acadêmico, validação de progresso e apresentações ao professor orientador.
Os registros de sprint documentam o desenvolvimento incremental, as decisões tomadas, os itens concluídos e os pontos ainda em evolução em cada período. As páginas de apresentação reúnem os materiais utilizados nas revisões formais do projeto.
Esses conteúdos são mantidos como histórico de entrega e evidência do processo de desenvolvimento. Algumas páginas podem conter itens incompletos, observações intermediárias ou campos sem preenchimento, pois refletem o estado registrado no momento de cada checkpoint.
